# 🩺 Parkinson Disease Prediction System

A Machine Learning based web application that predicts whether a person has Parkinson Disease using voice measurement data.

This project is built using:
- Python
- Machine Learning
- Random Forest Classifier
- Streamlit
- Scikit-learn
- Pandas & NumPy

# 🧠 Machine Learning Model

- Random Forest Classifier

The model was trained using:
- Voice measurement dataset
- Data preprocessing
- Feature scaling
- Train-test split

---

# 📊 Dataset Features

The model uses 22 voice measurement features including:

- MDVP:Fo(Hz)
- MDVP:Fhi(Hz)
- MDVP:Flo(Hz)
- MDVP:Jitter(%)
- MDVP:Shimmer
- HNR
- RPDE
- DFA
- PPE
- and more...

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ROUNAK-KUMAR-GUPTA/Parkinson-s-Diseases-Prediction-using-Voice-Analysis.git
```

Move into project folder:

```bash
cd Parkinson-s-Diseases-Prediction-using-Voice-Analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```
